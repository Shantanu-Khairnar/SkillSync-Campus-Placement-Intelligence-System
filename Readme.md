# SkillSync – Campus Placement Intelligence System

## Project Overview
SkillSync is a database-driven Campus Placement Intelligence System designed to manage student skills, company applications, interview rounds, and placement records.

The project aims to help college placement departments organize student placement data and analyze placement readiness using SQL and data analytics.

## Project Objectives
- Manage student and department information.
- Track student technical and soft skills.
- Maintain company and job application records.
- Monitor interview rounds and selection status.
- Track job offers and placement packages.
- Generate useful placement analytics.
